# Issue tracker

This repository uses GitHub Issues at `JamesbbBriz/agent-workflow`.

- Implementation-ready work carries the `ready-for-agent` label.
- Fetch an issue with `gh issue view <number> --repo JamesbbBriz/agent-workflow --comments`.
- Pull requests reference their ticket with `Closes #<number>` only when the ticket's complete acceptance criteria are met.
- Blocking edges are listed in each issue's **Blocked by** section.
- Do not close or rewrite a parent specification issue when completing a child ticket.
